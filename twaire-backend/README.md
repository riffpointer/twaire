# Twaire - Backend Server

The backend provides RESTful APIs and core business logic for Twaire. It handles data storage, authentication, and communication with other services.

### Configuration

Copy `.env.example` to `.env` and update environment variables as needed.

### Running the Server

```bash
npm run dev
```

## Project Structure

```
/src
    /controllers
    /models
    /routes
    /middlewares
```
